# Code of conduct

Kalkan follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and constructive, assume good faith, and keep the discussion
about the work. Harassment, insults and personal attacks are not tolerated, in
issues, pull requests, discussions or anywhere else the project is represented.
Criticism of the code — including blunt security criticism — is welcome; it is
what this project is for.

## Reporting

Contact the maintainer, @D3XSIM. If you need a private channel, use the form
under *Security → Report a vulnerability* and say that your report concerns the
code of conduct. Reports are handled confidentially.
